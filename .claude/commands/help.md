The full prompt for this command is at `.github/prompts/help.prompt.md`. Read it and follow it precisely.

The complete guide lives at `docs/getting-started.md` — `/help` is a digest with topic drill-downs.

Invocation patterns:

```
/help                  # friendly overview + goal-oriented workflows
/help agents           # all installed agents, when to call each
/help commands         # all slash commands organized by goal
/help concepts         # big ideas: dual-tool layout, specs, verification, debug surface
/help workflow         # greenfield + brownfield walkthroughs
/help debugging        # the debug-surface stages (1, 2, 2.5, 3)
/help updating         # versioning + /update-framework + bootstrap
/help faq              # common questions
```

Newbie-friendly. Plain language. No jargon without explaining. The first command to run after adopting the framework into a new project.
